# Atlas Z-Anatomy local

Os arquivos grandes não são versionados pelo Git. Para baixar e validar a
revisão reproduzível usada pelo aplicativo:

```bash
anatomia-dados instalar
anatomia-dados verificar
anatomia-dados relatorio
```

O instalador do Windows inclui esses arquivos. Versões, hashes, fontes e
licenças estão definidos em `src/anatomia_app/zanatomy.py` e documentados em
`THIRD_PARTY_LICENSES.md`.

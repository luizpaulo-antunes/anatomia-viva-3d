# Dados locais do BodyParts3D

Esta pasta recebe o arquivo oficial e as malhas extraídas pelo comando:

```bash
anatomia-dados instalar
```

O instalador aceita o arquivo oficial BodyParts3D 4.0 e também pode obter somente as malhas necessárias do espelho STL da versão 3.0. Os arquivos grandes são ignorados pelo Git. Consulte `THIRD_PARTY_LICENSES.md` antes de redistribuí-los.
